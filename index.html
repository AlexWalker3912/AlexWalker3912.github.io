OCKO Navigation
Drone Builder
Hardware Integration · Contract

Built drones from the ground up for OCKO Navigation, a startup making navigation hardware for environments where GPS can't be trusted — jammed, spoofed, or simply not there.

Each airframe is a test platform for OCKO's SR10 navigation module, so the build has to be right: clean power, clean wiring, and a payload mount that keeps the sensor rigid and isolated. Built in my own garage: assembled, soldered, printed, and debugged every one myself.
